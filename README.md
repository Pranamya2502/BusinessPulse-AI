# BusinessPulse AI

An end-to-end Data Science Analytics and Forecasting Platform built using Python, SQL, Machine Learning, Time Series Forecasting, and Streamlit.

## Tech Stack

- Python
- Pandas
- NumPy
- PostgreSQL
- SQLAlchemy
- Scikit-learn
- Prophet
- Plotly
- Streamlit

## Features

- Data Cleaning
- Exploratory Data Analysis
- SQL Analytics
- Customer Segmentation
- Sales Forecasting
- Interactive Dashboard
